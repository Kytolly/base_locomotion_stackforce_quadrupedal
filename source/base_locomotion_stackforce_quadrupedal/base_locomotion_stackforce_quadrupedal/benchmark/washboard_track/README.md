# Washboard Track

This directory owns the versioned washboard benchmark. The v2 track contains gentle entry/exit ramps and two staggered rows of seven bottle positions: twelve full transverse cylinders and two opposite-end boundary blocks. Geometry and seeded sampling follow `demo_mode_switching`'s washboard benchmark. `Base-Locomotion-Stackforce-Quadrupedal-Washboard-v0` renders and evaluates this geometry; generated reports belong under `output/benchmark/washboard/`. See `docs/BENCHMARKS.md` for dimensions and traversal criteria.
